Verified encoded folders and that calendars reside inside database folders rather than a generated root index.

The exact Python3.11.13 helper checked436 local references across20 pages and rejected a missing destination. A temporary loopback HTTP server served all four correctly encoded calendar entry URLs with status200, then was stopped. No browser was involved.

The plain-text custom%d prefix fixture omitted slash-name records; tagged source confirms its limited name matcher. JSON input processed those records. A per-database JSON diagnostic still included other database aggregates. The article discloses both limits and avoids claiming that directory separation establishes authorization.
