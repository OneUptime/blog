## Issues Found
- The template generator used `strings.ToLower` but did not import `strings`. Added the missing import.
- The `main.go` example used `fmt.Println` but did not import `fmt`. Added the missing import.
- The SQL query generator used `fmt.Fprintf` but did not import `fmt`. Added the missing import.
- The SQL query generator used deprecated `strings.Title`. Replaced it with a simple first-character uppercase conversion for the example constant name.
- The generated SQL file header did not match Go's generated-code marker convention. Updated it to `// Code generated by gen_queries.go; DO NOT EDIT.`
- The custom enum generator imported `strings` without using it. Removed the unused import.
- The custom enum generator only captured constants whose own `ValueSpec` repeated the enum type, so it missed typical `iota` constants that rely on the previous typed declaration. Updated the loop to remember the current const block type.

## Review Notes
The local environment did not have the Go toolchain available on `PATH`, so examples were reviewed statically against official documentation rather than compiled locally. The SQL query generator remains intentionally simple and assumes SQL files do not contain backticks in their contents.
