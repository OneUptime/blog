## Issues Found
- The example command for viewing istiod's ClusterRole used `istiod-istio-system`, which does not match current Istio chart naming. Changed it to `istiod-clusterrole-istio-system`.
- The restricted istiod ClusterRole omitted several permissions present in current Istio manifests that are commonly needed for service discovery, EndpointSlices, CRD discovery, Gateway API resources, ingress resources, token reviews, subject access reviews, service status updates, and status subresources. Expanded the example and added a version/feature caveat so readers start from their generated Istio manifest.
- The certificate signer example used `kubernetes.io/legacy-unknown`, which is not a safe current default. Replaced it with a placeholder signer and an instruction to use the signer configured for the installation.
- The Kyverno examples used top-level `validationFailureAction`, which current Kyverno documentation places under `validate.failureAction`. Updated both policies.
- The AuthorizationPolicy Kyverno example used `principals: "?*"`, which was not a correct list-shaped source constraint. Changed it to require non-empty `serviceAccounts`.
- The events audit command sorted by deprecated `lastTimestamp`. Replaced it with the current `kubectl events` command for warning events.
- The Prometheus alert filtered `apiserver_request_total` by a `user`/`username` label, but that metric does not include the requesting username. Changed the alert to detect 403 denials on sensitive resources and added a note that per-service-account alerting requires audit-log-derived metrics.

## Review Notes
`kubectl` is not installed in this review environment, so CLI behavior was verified against the official Kubernetes command reference instead of local command output. Istio RBAC varies by release, install profile, revision, and enabled features, so production changes should be based on manifests generated by the exact Istio release in use.
