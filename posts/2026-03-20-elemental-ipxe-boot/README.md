# How to Set Up Elemental with iPXE Boot

Author: [nawazdhandala](https://www.github.com/nawazdhandala)

Tags: Elemental, IPXE, Network Boot, Edge, Kubernetes

Description: Configure iPXE network boot for Elemental nodes to enable zero-touch provisioning without physical media.

## Introduction

iPXE network boot enables you to provision Elemental nodes without creating physical boot media for each machine. Machines boot from the network, load the Elemental environment, register with Rancher, and install the OS automatically. This is ideal for data center and factory environments where network infrastructure is available.

## Prerequisites

- DHCP server (for PXE option configuration)
- TFTP or HTTP server for serving boot files
- Elemental OS image available
- Network with PXE/iPXE boot support

## Step 1: Set Up the Boot Server

```bash
# Install required services on your boot server

zypper install dhcp-server tftpd

# Or on Ubuntu/Debian
apt-get install isc-dhcp-server tftpd-hpa

# Create directories for TFTP and HTTP boot files
mkdir -p /srv/tftp /srv/http/elemental

# Download iPXE chainloaders
curl -Lo /srv/tftp/ipxe.efi http://boot.ipxe.org/ipxe.efi
curl -Lo /srv/tftp/undionly.kpxe http://boot.ipxe.org/undionly.kpxe
```

## Step 2: Configure DHCP for PXE

```bash
# /etc/dhcp/dhcpd.conf
cat > /etc/dhcp/dhcpd.conf << 'EOF'
option domain-name "example.com";
option domain-name-servers 8.8.8.8, 8.8.4.4;
option client-arch code 93 = unsigned integer 16;

subnet 192.168.1.0 netmask 255.255.255.0 {
  range 192.168.1.100 192.168.1.200;
  option routers 192.168.1.1;

  # iPXE boot configuration
  if exists user-class and option user-class = "iPXE" {
    # iPXE already loaded, serve the boot script
    filename "http://192.168.1.10:8080/boot.ipxe";
  } else {
    # First boot, serve the correct iPXE loader for the client firmware
    if option client-arch != 00:00 {
      filename "ipxe.efi";
    } else {
      filename "undionly.kpxe";
    }
    next-server 192.168.1.10;
  }
}
EOF

# Restart the DHCP service
systemctl restart dhcpd

# Or on Ubuntu/Debian
systemctl restart isc-dhcp-server
```

## Step 3: Create iPXE Boot Script

```bash
# Create the iPXE boot script
cat > /srv/http/boot.ipxe << 'EOF'
#!ipxe

# Set variables
set base-url http://192.168.1.10:8080/elemental
set config-url http://192.168.1.10:8080/livecd-cloud-config.yaml

echo Booting Elemental OS...

# Download and boot kernel
kernel ${base-url}/linux \
  initrd=initrd \
  ip=dhcp \
  rd.cos.disable \
  root=live:${base-url}/rootfs.squashfs \
  console=tty1 \
  console=ttyS0,115200n8 \
  stages.initramfs[0].commands[0]="curl -fsSL ${config-url} > /run/initramfs/live/livecd-cloud-config.yaml"

# Load initrd
initrd ${base-url}/initrd

# Boot
boot
EOF
```

## Step 4: Serve Elemental Boot Files via HTTP

```bash
# Extract boot files from Elemental ISO
mkdir -p /mnt/iso
mount -o loop elemental.iso /mnt/iso

# Copy boot files used for network boot
cp "$(find /mnt/iso -name linux -type f -print -quit)" /srv/http/elemental/linux
cp "$(find /mnt/iso -name initrd -type f -print -quit)" /srv/http/elemental/initrd
cp "$(find /mnt/iso -name rootfs.squashfs -type f -print -quit)" /srv/http/elemental/rootfs.squashfs

umount /mnt/iso

# Start HTTP server
python3 -m http.server 8080 --directory /srv/http
```

## Step 5: Prepare the Elemental Registration File

```bash
# Download the registration file generated by MachineRegistration
wget --no-check-certificate \
  "$(kubectl get machineregistration -n fleet-default my-nodes -o jsonpath='{.status.registrationURL}')" \
  -O /srv/http/livecd-cloud-config.yaml
```

## Step 6: Test the Setup

```bash
# Create a test disk for the VM
qemu-img create -f qcow2 elemental-test.qcow2 30G

# Smoke-test the extracted Elemental boot artifacts in a VM
# QEMU user-mode networking exposes the host HTTP server as 10.0.2.2
qemu-system-x86_64 \
  -m 4096 \
  -drive file=elemental-test.qcow2,format=qcow2 \
  -kernel /srv/http/elemental/linux \
  -initrd /srv/http/elemental/initrd \
  -append 'initrd=initrd ip=dhcp rd.cos.disable console=ttyS0,115200n8 root=live:http://10.0.2.2:8080/elemental/rootfs.squashfs stages.initramfs[0].commands[0]="curl -fsSL http://10.0.2.2:8080/livecd-cloud-config.yaml > /run/initramfs/live/livecd-cloud-config.yaml"' \
  -netdev user,id=net0 \
  -device e1000,netdev=net0 \
  -nographic
```

## Monitoring iPXE Registrations

```bash
# Watch for new machine registrations
kubectl get machineinventory -n fleet-default --watch

# Check DHCP leases
grep "binding state active" /var/lib/dhcp*/dhcpd.leases
```

## Conclusion

iPXE network boot with Elemental eliminates the need for physical boot media, enabling fully automated provisioning at scale. By serving the Elemental registration file alongside the iPXE boot script, machines can go from bare metal to a registered Kubernetes node without any manual intervention, making it ideal for large-scale deployments.
