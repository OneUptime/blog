## Issues Found
- The prerequisites listed Kubernetes v1.25 or later, but current Flux documentation only supports current upstream Kubernetes versions and notes that older EOL versions are not supported. Changed this to require a Kubernetes cluster supported by the installed Flux version.
- The prerequisites listed Flux CLI v2.0 or later, but Flux documentation states the CLI is supported within one minor version of Flux. Changed this to require a CLI compatible with the installed Flux version.
- The controller image examples pinned `ghcr.io/fluxcd/kustomize-controller:v1.4.0`, which is outdated for the current Flux release. Updated both shard examples to `ghcr.io/fluxcd/kustomize-controller:v1.8.4`, the kustomize-controller version included with Flux v2.8.6.

## Review Notes
The sharding label selector examples, main-controller exclusion selector, Kustomization API version, `dependsOn` usage, kustomize-controller flags, and `flux get kustomizations --status-selector` commands match official Flux documentation. In production, the controller image should generally match the Flux component versions generated by the installed Flux release manifests.
