# How to Use Express with TypeORM

Author: [nawazdhandala](https://www.github.com/nawazdhandala)

Tags: Express.js, TypeORM, TypeScript, Database, Node.js

Description: Learn how to use Express with TypeORM for database operations including entities, repositories, relations, and migrations.

---

Combining Express with TypeORM gives you a clean, type-safe way to talk to a relational database from a Node.js application written in TypeScript. TypeORM maps your tables to entity classes, exposes repositories for querying and persisting data, models relationships between entities, and manages schema changes through migrations. This guide covers how these pieces fit together so you can wire a TypeORM data source into an Express app and keep your database access organized as the project grows.
