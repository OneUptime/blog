## Issues Found
- Removed `palindrome = 1` from the `pwquality.conf` example. `pam_pwquality` checks palindromes, but `palindrome` is not a supported `pwquality.conf` option in the documented configuration keys.
- Added a RHEL 9 caveat that `/etc/pam.d/system-auth` is usually generated by authselect. Direct inline PAM changes should be made through an authselect custom profile when changing the generated PAM stack.
- Updated the PCI DSS example from `minlen = 7` to `minlen = 12`. PCI DSS v4.0 Requirement 8.3.6 required 12-character passwords after March 31, 2025, so the old seven-character example was outdated for this 2026 post.
- Changed the "NIST 800-53" heading to "NIST SP 800-63B". The referenced password guidance about length, blocklists, and avoiding composition rules belongs to NIST SP 800-63B, not NIST SP 800-53.

## Review Notes
The `pwmake 128` example is technically valid as a libpwquality password generator with a 128-bit entropy request, but generated passwords should still be checked against the deployed policy with `pwscore` or an actual password-change test in environments with additional PAM or compliance controls.
