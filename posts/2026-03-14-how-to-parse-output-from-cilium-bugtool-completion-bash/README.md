## Introduction

Bash shell completion for cilium-bugtool enables tab completion of subcommands, flags, and arguments directly in your terminal. This reduces the need to consult help text and speeds up diagnostic workflows when collecting Cilium debugging data.




The bash completion script generated by cilium-bugtool uses Cobra's bash completion v2 format. The script calls back into `cilium-bugtool __complete` to obtain subcommands, flags, and shell completion directives at completion time.

This guide covers parsing techniques for extracting structured data from bash completion output.

## Prerequisites

- Bash shell
- `bash-completion` package installed
- `cilium-bugtool` binary available locally or in a Cilium pod
- `kubectl` access to a Cilium cluster (if binary is not local)

```bash

```

### Extracting Commands

```bash
## Extract top-level command names from Cobra completion output
cilium-bugtool __complete '' 2>/dev/null | awk -F'\t' '/^[[:alnum:]_-]/ {print $1}' | sort -u

## Extract subcommands for the completion command
cilium-bugtool __complete completion '' 2>/dev/null | awk -F'\t' '/^[[:alnum:]_-]/ {print $1}' | sort -u
```

### Extracting Flags

```bash
## Extract all top-level long flags
cilium-bugtool __complete -- 2>/dev/null | awk -F'\t' '/^--/ {print $1}' | sort -u

## Extract flags with their associated commands
for cmd in $(cilium-bugtool __complete '' 2>/dev/null | awk -F'\t' '/^[[:alnum:]_-]/ {print $1}'); do
  cilium-bugtool __complete "$cmd" -- 2>/dev/null | awk -F'\t' -v cmd="$cmd" '/^--/ {print cmd, $1}'
done
```

### Python-Based Parser

```python
#!/usr/bin/env python3
"""Parse cilium-bugtool bash completion for command and flag extraction."""

import re
import json
import sys
import subprocess

def complete(binary, *args):
    output = subprocess.run(
        [binary, '__complete', *args],
        check=False,
        text=True,
        stdout=subprocess.PIPE,
        stderr=subprocess.DEVNULL,
    ).stdout
    return [
        line.split('\t', 1)[0]
        for line in output.splitlines()
        if line and not line.startswith(':')
    ]

def parse_bash_completion(filepath, binary='cilium-bugtool'):
    with open(filepath, errors='ignore') as f:
        content = f.read()

    # Extract all unique top-level flags from Cobra's runtime completion API
    flags = sorted(item for item in complete(binary, '--') if item.startswith('--'))

    # Extract top-level commands from Cobra's runtime completion API
    commands = sorted(item for item in complete(binary, '') if re.match(r'^[A-Za-z0-9_-]+$', item))

    # Extract helper function names present in the generated bash script
    pattern = r'__cilium-bugtool_([A-Za-z0-9_]+)'
    handlers = sorted(set(re.findall(pattern, content)))

    return {
        'flags': flags,
        'commands': commands,
        'handlers': handlers,
        'total_lines': content.count('\n')
    }

if __name__ == '__main__':
    path = sys.argv[1] if len(sys.argv) > 1 else '/tmp/bugtool-bash-completion.sh'
    binary = sys.argv[2] if len(sys.argv) > 2 else 'cilium-bugtool'
    result = parse_bash_completion(path, binary)
    print(json.dumps(result, indent=2))
```

### Generating Documentation

```bash
## Convert parsed output to markdown
python3 parse_bash_completion.py /tmp/bugtool-bash-completion.sh |   jq -r '.flags[]' | while read -r flag; do
    printf -- '- `%s`\n' "$flag"
  done > /tmp/bugtool-flags.md

echo "Generated flag documentation at /tmp/bugtool-flags.md"
```

## Troubleshooting

- **Regex mismatches**: Bash completion format varies by Cobra version. Inspect the raw file first.
- **Empty command list**: Ensure `cilium-bugtool` is available and that the hidden `__complete` command returns results.
- **Python script errors on encoding**: Open files with `errors='ignore'` for robustness.
- **Missing flags in parsed output**: Some completions may be context-dependent; query the command path where the flag applies.
