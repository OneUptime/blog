## Issues Found
- The prerequisites used stale Node.js and backend tooling guidance. Updated Node.js from 18+ to 20+, added Mage, and aligned the Grafana baseline with the current scaffolded `grafanaDependency`.
- The setup section recommended globally installing `@grafana/create-plugin` and using a `--version` check that does not behave as written. Replaced it with the documented `npx @grafana/create-plugin@latest` flow and a simple `node --version` prerequisite check.
- The Docker commands used legacy `docker-compose` syntax and omitted the backend build step required for backend app plugins. Updated commands to `docker compose` and added `mage -v build:linux`.
- The sample plugin ID did not satisfy Grafana's documented plugin ID pattern. Replaced it with `yourorg-monitoring-app` throughout paths, API calls, tests, and backend registration.
- The backend-enabled `plugin.json` example omitted `backend` and `executable`. Added those fields and matched the executable name generated by current `create-plugin`.
- The TypeScript module and config examples had inconsistent settings typing and unused declarations. Exported `PluginSettings`, imported it in `module.ts`, and removed unused `useEffect` and `SecureSettings` from the config example.
- The Playwright test expected `[data-testid="service-card"]`, but the Dashboard example did not render that attribute. Added `data-testid="service-card"` to the card.
- The Go module import path and plugin ID in `main.go` used the old placeholder. Updated them to match the generated scaffold.
- The signing section used the old `GRAFANA_API_KEY` terminology and implied private-key generation. Updated it to use `GRAFANA_ACCESS_POLICY_TOKEN` and the documented `npm run sign -- --rootUrls ...` command.
- The signing-type table omitted commercial public plugins while saying there were only two options. Reworded the statement and added Commercial.
- The security checklist incorrectly framed CORS headers as the expected backend endpoint control. Replaced it with guidance to use Grafana resource routes instead of unauthenticated cross-origin endpoints.
