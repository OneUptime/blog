## Issues Found
- The post described encrypted Vault files as a "binary blob" and full-file encryption diffs as "binary diff" output. Ansible Vault files are UTF-8 text files with an encrypted payload and Vault header, so I changed these phrases to "encrypted text payload" and "opaque encrypted diff."
- The Python test hard-coded `tests/.vault_pass_test`, but the GitHub Actions workflow created `.vault_pass` from a CI secret before running that test. I changed the test to honor `ANSIBLE_VAULT_PASSWORD_FILE` with the test password file as the local default, and set that environment variable in the workflow.
- The `ansible.cfg` example was fenced as YAML even though the content is INI syntax. I changed the code fence to `ini`.

## Review Notes
- The Ansible Vault CLI flags shown for `encrypt`, `view`, `--vault-password-file`, and `--vault-id` match current Ansible documentation.
