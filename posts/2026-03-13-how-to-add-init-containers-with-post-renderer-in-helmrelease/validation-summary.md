## Issues Found
- The introduction said Flux post-renderers can inject init containers into any workload resource generated by a Helm chart. Flux documents that Helm post-renderers are not applied to chart hooks, so this was changed to "non-hook workload resources."
- Several init container examples included resource requests but no limits, while the conclusion says to include both requests and limits. Added conservative CPU and memory limits to those examples for consistency.

## Review Notes
The HelmRelease `apiVersion`, `spec.postRenderers.kustomize.patches` structure, Kustomize inline strategic merge patch format, Kubernetes `initContainers` placement, sequential init container behavior, and kubectl JSONPath usage are consistent with the official documentation. The StatefulSet example intentionally targets by kind only, which can patch multiple StatefulSets; in a real release, narrowing the target by name or labels may be safer.
