## Issues Found
- The post said `Microsoft.KeyVault.SecretNearExpiry` fires 30 days before expiry and is configurable. Microsoft documentation states secret and certificate near-expiry events fire 30 days before expiration, while key near-expiry timing can be configured using a key rotation policy. Updated the event list and explanatory paragraph.
- The Logic App JSON snippet contained JavaScript-style comments and an extra top-level `definition` wrapper, so it was not a valid workflow definition file for `az logic workflow create --definition`. Replaced it with valid JSON and clarified that connector-backed Logic App definitions require the Event Grid and email API connections to be created/configured.
- The Logic App Event Grid subscription command used `--endpoint-type azurefunction` and a Logic App trigger path. Azure CLI documentation defines `azurefunction` for Azure Function resource destinations, not Logic App workflow trigger paths. Replaced the command with guidance that the Logic Apps Event Grid trigger creates its own Event Grid subscription, and added a webhook-based alternative for Logic App HTTP Request triggers.
- The testing command used `date -u -v+29d`, which is a BSD/macOS `date` option and is not portable to Azure Cloud Shell or typical Linux Bash environments. Replaced it with GNU `date -u -d "+29 days"`.
- The Python sample used `datetime.utcnow()`, which returns a naive datetime and is deprecated in current Python guidance. Replaced it with `datetime.now(timezone.utc)`.
- The Python sample's placeholder rotation function used `pass`, which would return `None` and then attempt to write a null secret value. Replaced it with an explicit `NotImplementedError` so readers do not accidentally deploy an incomplete rotation implementation.
