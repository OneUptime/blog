## Issues Found
- The Falco chart version was pinned to `4.x`, which is outdated for the current official chart values used in the post. Updated it to `8.x`.
- The Falcosidekick chart version was pinned to `0.8.x`, while the current chart line is `0.13.x`. Updated the version range.
- The Falco Helm values used older camelCase Falco config keys such as `logLevel`, `jsonOutput`, `httpOutput`, `grpcOutput`, and `bindAddress`. Updated them to the current snake_case Falco config keys used by the chart.
- The Falco example enabled the legacy eBPF driver and deprecated gRPC output/server settings. Updated the driver to `modern_ebpf` and removed the deprecated gRPC output configuration.
- The Falcosidekick secret was created but not referenced by the HelmRelease. Added `config.existingSecret: falcosidekick-secrets`.
- The reverse shell rule had ambiguous boolean grouping. Added parentheses so the intended shell and command-line checks are explicit.
- The RBAC step was mislabeled as Pod Security / privileged access even though it grants Kubernetes metadata read access. Renamed and reworded the step and resource names.
- The ServiceMonitor section said it covered Falco and Falcosidekick metrics, but the manifest selects only Falcosidekick. Updated the wording.
- The verification command used `falco --list`, which lists fields, not loaded rules. Updated it to `falco -L`.
- The troubleshooting section checked kernel headers even though the guide uses eBPF. Updated it to check tracing filesystem access.
- The Falcosidekick health check used `/healthz`; the chart uses `/ping` for probes. Updated the command.
- The conclusion and architecture implied Prometheus receives forwarded alerts. Updated this to describe Prometheus metrics exposure instead.

## Review Notes
- Falco's official documentation now recommends the Falco Operator for Kubernetes, while the Helm chart remains supported. This guide is still technically valid as a Flux-managed Helm deployment.
- The Kubernetes metadata RBAC in the post overlaps with RBAC normally generated by the Falco Helm chart when `rbac.create` is enabled, but the example is valid.
