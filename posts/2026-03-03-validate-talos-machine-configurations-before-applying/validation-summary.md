## Issues Found
- The CI example used `talosctl gen config --from-secrets`, but current Talos CLI documentation uses `--with-secrets` for a secrets file generated by `talosctl gen secrets`. Updated the command to `--with-secrets secrets.yaml`.
- The running-configuration diff command wrote the full Talos resource wrapper to `running.yaml`, which would not compare cleanly with a proposed machine configuration file. Updated it to extract `.spec` with `yq`.
- The Python YAML syntax check used `import yaml`, which requires PyYAML and is not part of the Python standard library. Updated the comment to make that dependency explicit.

## Review Notes
The Talos validation, patching, install-script, dry-run, and network port examples align with current official Talos documentation. The examples are version-neutral, but Talos CLI flags should still be rechecked when targeting a specific Talos release because generated-config options can change between releases.
