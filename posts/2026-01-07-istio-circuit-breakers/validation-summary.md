## Issues Found
- The post used `networking.istio.io/v1beta1` for Istio `DestinationRule` and `VirtualService` examples. Updated the examples to `networking.istio.io/v1`, the current stable API used in Istio documentation.
- The prerequisites listed stale fixed minimum versions (`Kubernetes 1.21+` and `Istio 1.15+`). Replaced them with supported-version wording because Istio 1.15 is long out of support and current Istio releases support much newer Kubernetes versions.
- Several comments described `maxConnections` and `http2MaxRequests` incorrectly. Updated them to match Istio's current `DestinationRule` reference: `maxConnections` applies to HTTP/1.1 or TCP connections to a destination host, and `http2MaxRequests` limits active HTTP requests to the destination for HTTP/1.1 and HTTP/2.
- The advanced outlier detection examples used `minEjectionTime` and `maxEjectionTime`, which are not fields in the current Istio `DestinationRule` outlier detection schema. Removed those fields and the related comments.
- The examples set `consecutiveGatewayErrors` equal to `consecutive5xxErrors`, which makes the gateway error threshold ineffective because gateway errors are included in 5xx errors. Lowered `consecutiveGatewayErrors` to `3` where both settings are shown.
- The outlier detection test used Istio `VirtualService` fault injection to create 500 responses. That is not a valid test of backend host ejection because abort faults are generated by the client-side proxy rather than returned by individual upstream hosts. Reworked the test to call httpbin's `/status/500` endpoint so Envoy observes upstream 5xx responses.
- The monitoring section referenced deprecated Envoy outlier counters (`ejections_total` and `ejections_consecutive_5xx`). Updated the examples to use `ejections_enforced_total` and `ejections_enforced_consecutive_5xx`.
- The monitoring text implied circuit breaker stats are always exposed by Istio. Adjusted it to note that Envoy can expose these metrics and that Istio proxy stats configuration must include the desired cluster and outlier detection stats.
