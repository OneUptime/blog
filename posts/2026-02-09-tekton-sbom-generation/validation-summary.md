## Issues Found
- The original Tekton Tasks stored `sbom.json` in per-Task `emptyDir` volumes, so the publish Task could not read the SBOM generated by the generate Task. Changed the Tasks and Pipeline to use a declared `sbom-output` / `sbom-workspace` Tekton workspace.
- The original `crane append --new_layer /workspace/sbom.json` passed raw JSON where crane expects a tarball layer. Added a packaging step that creates `sbom.tar`, then publishes that tarball layer with `crane append`.
- The original verification command used `crane export ... sbom.json`, but `crane export` writes a tar archive. Changed it to export `sbom.tar` and extract `sbom.json` with `tar -xOf`.
- The original post described the crane output as an OCI artifact. `crane append` creates an image with an appended layer, not a first-class OCI artifact with artifact metadata. Updated the wording to "registry image containing the SBOM file."
- The original Task, Pipeline, and PipelineRun examples used deprecated `tekton.dev/v1beta1` APIs. Updated them to `tekton.dev/v1`. Left Tekton Triggers as `triggers.tekton.dev/v1beta1`, which is still the documented Triggers API.
- The original Pipeline referenced deprecated `ClusterTask` resources for `git-clone` and `buildah` without showing how to install them. Added `tkn hub install task` commands and updated the Pipeline to reference namespaced Tasks.
- The original validation step used `jq` inside the Syft image without ensuring `jq` was present. Changed validation to an Alpine step that installs `jq`.
- The original component-count validation only worked for CycloneDX JSON. Updated the `jq` expression to handle CycloneDX `components`, SPDX `packages`, and Syft JSON `artifacts`.
- The original Syft and Cosign script steps assumed shell availability in minimal tool images. Switched Syft to the debug image for the shell script and invoked Cosign directly using `/ko-app/cosign`.
- The original Cosign image reference used the older `gcr.io/projectsigstore/cosign` path. Updated it to the documented `ghcr.io/sigstore/cosign/cosign` image.
- The original Cosign verification command omitted the required keyless verification identity and issuer flags. Added `--certificate-identity` and `--certificate-oidc-issuer` placeholders.
- The original Alpine helper image version was outdated for the review date. Updated helper steps to `alpine:3.23`.

## Review Notes
The pipeline still uses example `latest` tags for crane and cosign. Pinning all tool images by version or digest would improve reproducibility for a production tutorial, but the examples now use current APIs and corrected command semantics.
