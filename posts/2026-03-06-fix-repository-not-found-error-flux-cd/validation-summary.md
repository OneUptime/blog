## Issues Found
- The GitHub-specific error block was marked as `python`, even though it is plain terminal output. Changed the code fence to `text`.
- The URL typo checklist implied that HTTP versus HTTPS is the key protocol mistake. Flux supports HTTP/S and SSH URLs, but its documentation specifically warns that scp-like SSH URLs such as `git@github.com:org/repo.git` are not supported. Updated the checklist to call out unsupported SSH URL format instead.
- The renamed repository diagnostic said Git operations may not follow redirects. That is too broad. Updated the note to say Flux should point at the current canonical URL even when GitHub redirects old repository paths.
- The GitHub SAML SSO diagnostic suggested calling the organization endpoint and looking for `saml` in the response. GitHub documents SAML authorization failures through 403/404 responses and the `X-GitHub-SSO` response header for classic PATs. Replaced the command with a repository API request using `curl -i` and instructions to inspect the status/header.
- The prevention section described GitHub App tokens as long-lived credentials. GitHub App installation tokens are short-lived; the managed app authentication flow can issue them automatically. Updated the wording accordingly.
