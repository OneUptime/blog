## Issues Found
- The MongoDB role used `ansible.builtin.apt_key`, which depends on the deprecated `apt-key` flow. Replaced it with a keyring file generated by `gpg --dearmor` and referenced it with `signed-by`, matching current MongoDB and Ansible guidance.
- The MongoDB role enabled authorization and then attempted to create only an application user without authenticating. Added admin credentials, created the first admin user through the localhost exception, and then created the application user using that admin login.
- The Angular build task used `npm run build --production`, which is not the current Angular CLI production configuration form. Changed it to pass `--configuration production` to the build script.
- The application role built the Angular frontend without installing frontend dependencies. Added a frontend dependency installation task for `{{ app_dir }}/client`.
- The PM2 task used `pm2 start`, which can create duplicate managed processes on repeated deployments. Changed it to `pm2 startOrReload` for ecosystem-file deployments.

## Review Notes
The snippets remain generic and assume an Ubuntu release supported by the selected MongoDB version. MongoDB 7.0 supports Ubuntu 20.04 and 22.04 in the official documentation consulted; deployments on newer Ubuntu releases should verify MongoDB repository support before using `ansible_distribution_release` directly.
