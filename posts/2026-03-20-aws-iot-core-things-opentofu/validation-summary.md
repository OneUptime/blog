## Issues Found
- The certificate attachment example referenced `aws_iot_policy.device_policy` without defining the `aws_iot_policy` resource. I added a minimal `aws_iot_policy` block so the example is runnable.
- The tag examples used `var.environment`, but the post never declared that variable. I replaced those references with a literal tag value so the snippets are self-contained.
- The summary said the configuration enables "fleet provisioning", which is a separate AWS IoT feature built around provisioning templates. I reworded that line to describe device registry and lifecycle management instead.

## Review Notes
- `aws_iot_certificate.certificate_pem` and `aws_iot_certificate.private_key` are valid outputs for certificates generated by AWS, but they are sensitive values that end up in OpenTofu state and can also be present in saved plan files.
- `aws_iot_thing_principal_attachment` defaults to `NON_EXCLUSIVE_THING`. That is technically valid here, but posts that later rely on exclusive thing association behavior should set `thing_principal_type = "EXCLUSIVE_THING"` explicitly.
