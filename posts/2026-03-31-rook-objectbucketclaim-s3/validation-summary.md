## Issues Found

### 1. Wrong resource kind for bucket class: `StoreBucketClass` should be `StorageClass`
The post used a fabricated CRD kind `StoreBucketClass` with apiVersion `objectbucket.io/v1alpha1`. The OBC framework uses standard Kubernetes `StorageClass` (apiVersion `storage.k8s.io/v1`) to define bucket provisioning parameters. Fixed the kind, apiVersion, section heading, prerequisites text, and kubectl commands throughout.

### 2. StorageClass incorrectly had a namespace
The post included `namespace: rook-ceph` in the StorageClass metadata. StorageClass is a cluster-scoped resource and cannot be namespaced. Removed the namespace field.

### 3. Wrong OBC spec field: `storeBucketClassName` should be `storageClassName`
The ObjectBucketClaim spec uses `storageClassName` to reference the StorageClass, not `storeBucketClassName`. Fixed in all three OBC YAML examples (generated name, specific name, and quota examples).

### 4. Non-existent ConfigMap key: `BUCKET_SSL`
The ConfigMap example included `BUCKET_SSL: "false"` which is not a standard field generated by the OBC provisioner. The actual standard fields are: `BUCKET_HOST`, `BUCKET_PORT`, `BUCKET_NAME`, `BUCKET_REGION`, and `BUCKET_SUBREGION`. Replaced `BUCKET_SSL` with `BUCKET_SUBREGION`.

Since the radosgw-admin commands are shown as separate lines meant to be run inside the exec session, readers will need to add `-it` themselves.
