## Review Notes
- `snap interfaces <snap>` is still functional in current snapd but `snap connections <snap>` is the more modern preferred command; the post correctly shows both.
- `cat /etc/apparmor.d/docker-default` may not always succeed because Docker's default AppArmor profile is generated by the Docker daemon and loaded into the kernel at runtime — on some installations the file is not persisted to disk. `sudo aa-status | grep docker` (which the post also includes) is the more reliable check.
- `apparmor_parser -p` is documented as "preprocess and dump to stdout"; it will surface syntax errors as a side effect, so its use as a syntax-check step is reasonable, though there is no dedicated `--check` flag.
- The denial-log timestamp `audit(1709000000.123:456)` corresponds to February 2024, which is plausibly old enough to read as illustrative rather than a current event — fine as an example.
