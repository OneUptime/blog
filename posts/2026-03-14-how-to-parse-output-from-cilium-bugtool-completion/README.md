## Introduction

The `cilium-bugtool` command includes a `completion` subcommand that generates shell completion scripts. These completions enable tab-completion of cilium-bugtool subcommands, flags, and arguments in your terminal, making diagnostic workflows faster and less error-prone.




The completion scripts generated by cilium-bugtool use Cobra's dynamic completion protocol to request command, flag, and description candidates from the binary. Querying that protocol enables automated documentation generation, CLI coverage validation, and custom tooling.

This guide covers techniques for extracting structured data from cilium-bugtool completion output.

## Prerequisites

- `cilium-bugtool` binary available locally or in a Cilium pod
- Shell environment (Bash 4+, Zsh 5+, Fish 3+, or PowerShell 5+)
- `kubectl` access to a Cilium cluster (if binary is not local)

## Capturing the Completion Output




```bash
## Capture completion output for analysis
cilium-bugtool completion bash > /tmp/bugtool-completion.bash
cilium-bugtool completion zsh > /tmp/bugtool-completion.zsh

## Capture dynamic completion candidates used by the generated scripts
cilium-bugtool __complete "" > /tmp/bugtool-root-completions.txt 2>/dev/null
cilium-bugtool __complete -- > /tmp/bugtool-flag-completions.txt 2>/dev/null
```

### Extracting Subcommands

```bash
## Extract root commands with descriptions
awk -F '\t' '$1 !~ /^--/ && $1 !~ /^:/ { print $1 ": " $2 }' /tmp/bugtool-root-completions.txt | sort -u

## Extract command names only
awk -F '\t' '$1 !~ /^--/ && $1 !~ /^:/ { print $1 }' /tmp/bugtool-root-completions.txt | sort -u
```

### Extracting Flags

```bash
## Extract all long flags from the dynamic completion candidates
awk -F '\t' '$1 ~ /^--/ { print $1 }' /tmp/bugtool-flag-completions.txt | sort -u

## Extract flags with descriptions
awk -F '\t' '$1 ~ /^--/ { print $1 ": " $2 }' /tmp/bugtool-flag-completions.txt | sort -u
```

### Python Parser

```python
#!/usr/bin/env python3
import json
import subprocess

def complete(*args):
    output = subprocess.check_output(
        ['cilium-bugtool', '__complete', *args],
        stderr=subprocess.DEVNULL,
        text=True,
    )
    rows = []
    for line in output.splitlines():
        if not line or line.startswith(':'):
            continue
        value, _, description = line.partition('\t')
        rows.append((value, description))
    return rows

def parse_completion():
    root = complete('')
    flag_rows = complete('--')
    commands = [{'name': value, 'description': description}
        for value, description in root if not value.startswith('--')]
    flags = [{'flag': value, 'description': description}
        for value, description in flag_rows if value.startswith('--')]
    return {'flags': flags, 'commands': commands}

if __name__ == '__main__':
    print(json.dumps(parse_completion(), indent=2))
```

## Troubleshooting

- **Regex finds no matches**: The dynamic completion output includes a final Cobra directive line beginning with `:`. Filter that line before parsing candidates.
- **Duplicate entries**: Add deduplication with \`sort -u\` or Python \`set()\`.
- **Missing commands in parsed output**: Query the relevant command path with \`cilium-bugtool __complete <subcommand> ""\` and compare with \`cilium-bugtool --help\`.
- **JSON output is invalid**: Use \`json.dumps()\` so special characters in command descriptions are escaped correctly.
