## Issues Found
- The first start command did not include `systemctl --user daemon-reload`. Added it before `systemctl --user start webapp` because newly placed Quadlet files must be generated by systemd before the service can be started reliably.
- The DNS example said containers on the same network can reach each other by name without qualifying that DNS support must be enabled. Updated the sentence to say "DNS-enabled network" because Podman name resolution depends on DNS support for the network.
- The DNS test used `podman exec frontend curl ...` inside an `nginx:alpine` container. That image should not be assumed to include `curl`. Updated the frontend example to use the Python image already used elsewhere in the section, then replaced the command with a Python `urllib.request` check from `frontend` to `backend`.
