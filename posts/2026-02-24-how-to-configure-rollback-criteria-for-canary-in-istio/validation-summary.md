## Issues Found
- The post described `threshold: 3` as three consecutive metric check failures. Flagger documents the threshold as the maximum number of failed checks before rollback, and webhook failures also increment failed checks. Updated the wording to "three failed metric or webhook checks."
- The time-to-rollback explanation implied a fixed 90-second rollback for `threshold: 3` and `interval: 30s`. Updated it to clarify that this timing applies if each analysis loop continues to fail.
- The webhook failure description said a non-200 response counts as failure. Flagger treats HTTP 2xx responses as successful and timeout or non-2xx responses as failures. Updated the wording.
- The manual rollback command used an undocumented `flagger.app/rollback=true` annotation. Flagger documents manual rollback through a `rollback` webhook and the load tester `/rollback/open` endpoint. Replaced the annotation with a rollback webhook example and the documented load tester curl command pattern.

## Review Notes
