## Review Notes
- The example dedup key in the bash section (`a1b2c3d4e5f6g7h8`) contains characters `g` and `h`, which are not valid hexadecimal characters. Since `hashlib.sha256().hexdigest()` only produces `[0-9a-f]`, a real key generated by `make_dedup_key` would never contain `g` or `h`. This is cosmetic — the example is clearly a placeholder and does not affect any functional guidance.
- The implementation uses separate `SET NX` and `LPUSH` commands rather than a Lua script or transaction. If a process crashes after acquiring the dedup slot but before the `LPUSH`, the dedup key will be set but the job never enqueued (the job would be silently dropped until the TTL expires). This is a known tradeoff and not an error — the post does not claim crash safety. A production hardening note could mention this in the future.
- The `dict | None` union type syntax requires Python 3.10+. This is current and not deprecated, but readers on older Python versions would need `Optional[dict]` from `typing`.
