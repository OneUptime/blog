## Review Notes
- The SQL DDL generated by MySQL Workbench typically also includes an explicit index on foreign key columns (e.g., `INDEX fk_orders_customer_id_idx (customer_id ASC)`). The post omits this, which is acceptable since InnoDB automatically creates an implicit index on FK columns, and the exact Workbench output varies by version and settings.
- The post mentions manually defining `customer_id` in the `orders` table, then later shows the relationship tool adding it automatically. In practice, if the column already exists with the correct name and type, Workbench may reuse it; otherwise it creates a new one. This is a minor pedagogical point rather than a technical error.
- All menu paths, tool names, column flag abbreviations, relationship types, and SQL syntax are accurate for current versions of MySQL Workbench.
