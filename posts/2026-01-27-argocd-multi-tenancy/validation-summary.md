## Issues Found
- The AppProject example described `namespaceResourceBlacklist` as denying deployments to namespaces. Changed the comment to state that it denies namespace-scoped resource kinds, which matches the AppProject field semantics.
- Argo CD configuration ConfigMap and Secret examples omitted the `app.kubernetes.io/part-of: argocd` label. Added the label to the RBAC, SSO, command-params, notifications, and SSO secret snippets so Argo CD can reliably recognize the declarative configuration resources.
- The project role JWT token comment said tokens with the listed subject get the role. Changed it to describe the field as JWT token metadata generated by the Argo CD API server.
- The audit logging command-params snippet included `application.log.format`, which is not a documented `argocd-cmd-params-cm` key. Removed it and replaced the snippet with documented component log format/level keys.
- The notifications audit example defined a webhook service, template, and trigger, but did not subscribe applications to the trigger. Added a global `subscriptions` entry using the webhook recipient name.
- The sync window AppProject example omitted the Argo CD namespace. Added `metadata.namespace: argocd`, consistent with Argo CD's declarative setup requirements for AppProject resources.
