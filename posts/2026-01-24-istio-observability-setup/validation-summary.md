## Issues Found
- The introduction overstated default behavior by saying every request generates metrics, traces, and logs. Updated it to clarify that metrics are generated by mesh traffic, while sampled traces and access logs require the relevant telemetry configuration.
- The addon example used `istio-1.20.0`, which is outdated relative to the current Istio documentation reviewed on 2026-06-19. Updated the directory example to `istio-1.30.1`.
- The Prometheus `istiod` scrape job selected pods by label instead of the documented `istiod;http-monitoring` endpoint. Updated the scrape config to match the official Istio Prometheus integration example.
- The Envoy scrape job rewrote the address using `__meta_kubernetes_pod_annotation_prometheus_io_port`, which may not exist and is not part of the official Istio Envoy scrape example. Removed that relabel rule.
- Telemetry examples used `telemetry.istio.io/v1alpha1`. Updated applicable snippets to `telemetry.istio.io/v1`, matching the current stable API.
- The tracing example used legacy `MeshConfig` Zipkin tracing fields. Replaced it with an Istio `extensionProviders` configuration and a `Telemetry` resource using `randomSamplingPercentage`, following current Istio guidance.
- The Jaeger example used an old all-in-one image and did not expose OTLP ports needed by the current Istio Jaeger tracing configuration. Updated the image to `jaegertracing/all-in-one:1.76.0`, enabled OTLP, and exposed ports `4317` and `4318`.
- The Kiali manual Deployment example was incomplete for a working production installation because it omitted required operator-managed resources such as RBAC and Service resources. Replaced it with the recommended Kiali Operator Helm installation and current Kiali CR settings.
- The access log filter did not handle requests where `response.code` is absent, such as connection failures. Updated the CEL expression to include `!has(response.code)`.
- The production checklist used `curl` inside the `istio-proxy` container, which is not guaranteed to exist. Replaced it with the documented `pilot-agent request GET stats/prometheus` command.
- The access log grep example assumed JSON log output without configuring JSON logging. Updated it to a text-log-compatible 5xx filter.

## Review Notes
- The Istio sample addons remain appropriate for quick starts and demos, but the official documentation states they are not tuned for production performance or security.
- The Prometheus resource sizing table is a reasonable planning example, but production sizing should still be based on mesh size, scrape interval, retention, label cardinality, and query load.
- Kiali tracing integration depends on the Jaeger endpoint exposed in the cluster. The example uses a non-gRPC tracing URL because the post's Jaeger `tracing` service exposes the UI HTTP port.
