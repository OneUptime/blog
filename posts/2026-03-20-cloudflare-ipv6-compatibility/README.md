# How to Configure Cloudflare IPv6 Compatibility

Author: [nawazdhandala](https://www.github.com/nawazdhandala)

Tags: Cloudflare, IPv6, CDN, DNS, Compatibility, Web

Description: A guide to Cloudflare's IPv6 compatibility feature, including how to enable it, how it works, and how it provides IPv6 access to IPv4-only origins.

Cloudflare gives you two ways to handle IPv6: **IPv6 Compatibility** (automatic AAAA DNS records for Cloudflare-proxied records) and manual IPv6 DNS record management. When IPv6 compatibility is on, Cloudflare auto-generates AAAA DNS records for proxied hostnames even if your origin server only has an IPv4 address.

## How Cloudflare IPv6 Compatibility Works

```text
IPv6 Client → Cloudflare Edge (IPv6) → Cloudflare Network → Your Origin (IPv4)
              ↑ Cloudflare auto-generates AAAA DNS records for proxied hostnames
              ↑ Terminates the IPv6 client connection and opens an IPv4 connection to your origin
```

Your origin server can remain IPv4-only. Cloudflare terminates the client connection at its edge and connects separately to your origin over IPv4.

## Checking or Enabling IPv6 Compatibility

IPv6 compatibility is enabled by default for proxied records. On Enterprise plans, where the setting is editable, you can confirm or change it in the dashboard or via API.

### Via Cloudflare Dashboard

1. Log in to Cloudflare Dashboard
2. Select your domain
3. Navigate to **Network** tab
4. If the control is available for your plan, set **IPv6 Compatibility** to **On**

### Via Cloudflare API

```bash
# On Enterprise zones where the setting is editable, turn IPv6 Compatibility on

curl -X PATCH "https://api.cloudflare.com/client/v4/zones/{zone_id}/settings/ipv6" \
  -H "Authorization: Bearer $CF_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"value": "on"}'

# Verify the setting
curl "https://api.cloudflare.com/client/v4/zones/{zone_id}/settings/ipv6" \
  -H "Authorization: Bearer $CF_API_TOKEN"
```

### Via Terraform (Cloudflare Provider)

```hcl
resource "cloudflare_zone_setting" "ipv6" {
  zone_id    = var.zone_id
  setting_id = "ipv6"
  value      = "on"
}
```

## Verifying IPv6 Compatibility

```bash
# For proxied records, Cloudflare should return AAAA records when IPv6 compatibility is on
dig AAAA example.com

# Expected: AAAA records generated by Cloudflare for the proxied hostname
# example.com. 300 IN AAAA <Cloudflare-managed IPv6 address>

# Test IPv6 connection
curl -6 https://example.com/

# Check that origin receives connection (via Cloudflare dashboard or logs)
```

## IPv6 with Cloudflare DNS-Only Records (Orange Cloud Off)

When the orange cloud is off (DNS only, no proxy), you manage IPv6 directly:

```hcl
# Direct AAAA record (bypasses Cloudflare proxy)
resource "cloudflare_dns_record" "aaaa_direct" {
  zone_id = var.zone_id
  name    = "direct"
  type    = "AAAA"
  content = "2001:db8::1"
  proxied = false    # DNS only, no Cloudflare proxy
  ttl     = 300
}

# Proxied AAAA record (through Cloudflare)
resource "cloudflare_dns_record" "aaaa_proxied" {
  zone_id = var.zone_id
  name    = "@"
  type    = "AAAA"
  content = "2001:db8::1"
  proxied = true     # Traffic goes through Cloudflare
  ttl     = 1        # Auto TTL when proxied
}
```

## Cloudflare Page Rules and IPv6

Cloudflare page rules apply equally to IPv4 and IPv6 client connections:

```bash
# Create a page rule that redirects matching HTTP requests for both IPv4 and IPv6 clients
curl -X POST "https://api.cloudflare.com/client/v4/zones/{zone_id}/pagerules" \
  -H "Authorization: Bearer $CF_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "targets": [{"target": "url", "constraint": {"operator": "matches", "value": "http://example.com/*"}}],
    "actions": [{"id": "always_use_https"}],
    "status": "active"
  }'
```

## Checking Client IPv6 in Cloudflare Analytics

Cloudflare Analytics can help you inspect IPv4 and IPv6 traffic for proxied zones:

1. Cloudflare Dashboard → Analytics & Logs → HTTP Traffic
2. Review the traffic breakdowns available for your zone
3. Compare IPv4 and IPv6 request percentages when IP version data is exposed in your plan/UI

## IPv6 Client IP in Cloudflare Workers

```javascript
// Access the client's IPv6 address in a Cloudflare Worker
export default {
  async fetch(request) {
    const clientIP = request.headers.get("CF-Connecting-IP");
    const ipVersion = clientIP ? (clientIP.includes(":") ? "IPv6" : "IPv4") : "unknown";

    return new Response(`Your IP: ${clientIP ?? "unavailable"} (${ipVersion})`);
  },
};
```

Cloudflare's IPv6 Compatibility feature is the zero-effort path to IPv6 support - for proxied records it is on by default, and on Enterprise plans the setting can be customized in the dashboard or API without requiring your origin to listen on IPv6.
