## Review Notes
- `phx-feedback-for` (used in the field-level error display section) was deprecated in Phoenix LiveView 1.0 in favor of `Phoenix.Component.used_input?/1`. It is still functional in current versions but newer projects generated by `mix phx.new` use the `used_input?` approach instead. Worth noting as a future-update opportunity.
- The password strength indicator uses 5 checks (length, lowercase, uppercase, digit, special) producing strength values 0–5, but the bar rendering iterates `1..4`, so the visual maxes out at 4 filled bars even when strength is 5. This is a minor UI inconsistency, not a correctness bug.
- `unsafe_validate_unique/3` is correctly described — Ecto's actual head is `unsafe_validate_unique(changeset, fields, repo, opts \\ [])` so both arity 3 and 4 are valid.
- The `Heroicons.exclamation_circle mini` syntax assumes the `heroicons` Elixir library is installed. The newer Phoenix generator uses `<.icon name="hero-exclamation-circle" />` via inline SVG, but `Heroicons.exclamation_circle` is still a valid third-party library API.
